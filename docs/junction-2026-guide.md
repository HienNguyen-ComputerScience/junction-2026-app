# Junction 2026 — what matters for our team

Extracted from the official Participant Guidebook (13–15 Nov 2026, Hype Areena, Espoo). Theme: **European Tech Renaissance**. Platform: hackjunction.app. Discord: discord.gg/NMDxBZEep. Questions: hello@hackjunction.com.

## Hard rules (break one = no prize)

- **No code written before the event.** All code outside open-source libraries must be written at the event. Pre-built code for this idea, or a project tied to an existing company, means disqualification.
- Team size 1–4.
- Must enter at least one challenge (multiple allowed).
- **Whole team must attend live peer reviewing, Sun 10:30–14:00**, or we lose main-prize eligibility.
- Submission must include a **pitch video, max 2:00** (strictly enforced).
- Source code link required; organizers must be able to access it. **All submissions are MIT-licensed.** Repo must be public (or shared) by submission.
- Partner APIs/materials stay under partner terms.

## How we're judged

Overall (peer review → top 5 → 7 judges):
- **Innovation:** new/different vs. other projects?
- **Impact:** significant societal impact; share of affected people actually helped.
- **Implementation:** realistic, viable, feasible.

Challenge winners are picked by each partner using **their own criteria** — read the chosen challenge's judging criteria on the platform before we commit to scope.

## Top-5 pitch format

- Exactly 3 min pitch (mic cut at time), then 3 min judge Q&A.
- One handheld mic; one presenter recommended.
- Live demo from our own laptop is allowed (connection checked beforehand).
- No practice time after reviewing ends — rehearse before Sunday.
